# Data Sovereignty Experiments

## Purpose
This directory contains hands-on experiments designed to build practical capability in **data sovereignty**, **data governance**, and **ecosystem control**.

These experiments are intentionally structured as *learning vehicles*, not production implementations. Each experiment produces evidence, tradeoff analysis, and decision signals that may later inform:
- Architecture standards
- Governance policies
- Vendor requirements
- Formal Architecture Decision Records (ADRs)

## How This Fits Into the Repository
- **Playbooks** describe *how we experiment*
- **Experiments** generate *evidence and insight*
- **ADRs** capture *durable decisions*
- **Platform baselines** (e.g., Fedora) implement decisions in specific environments

This separation keeps experimentation safe, explicit, and reversible.
